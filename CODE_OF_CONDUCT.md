# Code of conduct

Project participation must be respectful, professional, and free of harassment,
discrimination, threats, doxxing, and deliberate disclosure of private repository or
benchmark material. Technical disagreement is welcome; personal attacks and misleading
public evidence claims are not.

Maintainers may edit or remove comments, issues, and contributions that violate these
standards and may restrict participation for repeated or severe violations. Enforcement
should consider context, impact, and a proportionate response.

For platform abuse, use GitHub's report-abuse controls. For a project enforcement concern,
open an issue containing only a request for a confidential contact channel; do not include
sensitive details in the issue. Vulnerabilities follow [`SECURITY.md`](SECURITY.md).

Attribution: these expectations are informed by the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
