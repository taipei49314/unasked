# Support

UNASKED is alpha research software without a service-level guarantee.

- For reproducible bugs and documentation problems, use the bug report template.
- For proposed behavior, use the feature request template.
- For vulnerabilities, use the private process in [`SECURITY.md`](SECURITY.md).
- For release files, verify `SHA256SUMS.txt` before installation.

Include the UNASKED version, operating system, Python and Git versions, the redacted JSON
output of `unasked --json doctor`, and a minimal reproduction. Never attach credentials,
private target source, sealed benchmark content, provider secrets, or an `.unasked`
workspace that has not been reviewed for sensitive evidence.

Support responses and software releases cannot authorize `VERIFIED` evidence or an M0 claim.
