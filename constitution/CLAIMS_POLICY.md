# Claims policy

## P0 / v0.1 permitted

> A research harness for blind, evidence-gated repository investigation.

## Forbidden at P0

- autonomous discovery agent;
- finds unknown bugs;
- self-driving researcher;
- validated proactive intelligence;
- globally novel finding;
- demonstrated blind discovery, unless an independently held sealed evaluation has passed.

The CLI emits `NO_VERIFIED_DISCOVERY` when no certificate passes the deterministic gate.
Candidates, supported hypotheses, and reproduced observations are never silently promoted
or included in a verified-only report.

## Later claims

- M0: blind discovery of reproducible discrepancies on a named sealed evaluation set.
- M2: autonomous experiment design for named discrepancy classes.
- M4: continuous proactive repository discovery with measured interruption precision.

Every later claim must name the software version, protocol hash, benchmark boundary,
aggregate false-positive controls, replay format, and limitations.
